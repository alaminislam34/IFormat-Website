# Project: iFormat Frontend Development

## Overview
This is a modern front-end project focused on delivering a highly performant, visually stunning, and smooth user experience. The backend will be developed in the future, but the current priority is establishing a robust front-end architecture.

## Goals & Directives
1. **Perfect Architecture:** Maintain a strict, professional component-based structure. Everything must be highly reusable, scalable, and modular.
2. **Smooth UX:** Utilize `lenis` for global smooth scrolling to provide a premium feel.
3. **Design System:** Use Tailwind CSS with `app/globals.css` to store and manage the global theme tokens. Consistency in design across all components is paramount.
4. **Reusable Components:** Build highly flexible, reusable components (like Buttons, Inputs, etc.) that support basic customization out of the box.
5. **Performance:** Optimize the app to load super fast and run smoothly without jank.

## Tech Stack
- Next.js (App Router)
- React
- Tailwind CSS v4
- Lenis (Smooth Scrolling)
